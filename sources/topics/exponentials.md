# Exponentials / توابع نمایی

Original MathTutor curated notes (Phase W3). Project exposition, not a textbook transcript. Reference: College Algebra 2e, sections 6.1–6.2 and 6.7. Checkable formulas were verified with SymPy; see `sources/manifests/curated_verification.json`.

## Beginner / مبتدی

### Definition / تعریف
An exponential function grows by repeated multiplication, not by repeated addition. Start from a small table of values, name the base, and separate "the base is multiplied" from "the base is added". For a fixed base b > 0 with b != 1, the exponential function is f(x) = b^x, where the variable x sits in the exponent and may be any real number. The base b is the constant factor applied at each step. Two values are fixed for every admissible base: b^0 = 1, so the graph always passes through (0, 1), and b^1 = b. When b > 1 the function increases; when 0 < b < 1 it decreases.
تابع نمایی با ضرب مکرر رشد می‌کند، نه با جمع مکرر. از یک جدول کوچک مقادیر شروع کن، پایه را نام بگذار و «ضرب در پایه» را از «جمع با پایه» جدا کن. برای پایه ثابت b > 0 با b != 1، تابع نمایی f(x) = b^x است، که در آن متغیر x در توان قرار دارد و می‌تواند هر عدد حقیقی باشد. پایه b ضریب ثابتی است که در هر گام اعمال می‌شود. دو مقدار برای هر پایه مجاز ثابت‌اند: b^0 = 1 پس نمودار همیشه از (0, 1) می‌گذرد، و b^1 = b. برای b > 1 تابع صعودی و برای 0 < b < 1 نزولی است.

### Rule and conditions / قاعده و شرطها
The base must satisfy b > 0 and b != 1, and the exponent may be any real number. Additive laws for exponents: b^(x+y) = b^x * b^y, b^(x-y) = b^x / b^y, and b^(-x) = 1 / b^x. Multiplicative law: (b^x)^y = b^(x*y). Domain: all real x. Range: b^x > 0 for every real x, so the output is never zero and never negative. The graph has the horizontal line y = 0 as an asymptote: b^x approaches 0 as x decreases without bound when b > 1. The exponential and the logarithm are inverse functions, so b^(log_b(x)) = x for x > 0 and log_b(b^x) = x for every real x.
پایه باید b > 0 و b != 1 را برآورده کند و توان می‌تواند هر عدد حقیقی باشد. قوانین جمعی توان: b^(x+y) = b^x * b^y، b^(x-y) = b^x / b^y و b^(-x) = 1 / b^x. قانون ضربی: (b^x)^y = b^(x*y). دامنه: همه x حقیقی. برد: b^x > 0 برای هر x حقیقی، پس خروجی هرگز صفر یا منفی نیست. نمودار خط افقی y = 0 را به‌عنوان مجانب دارد: برای b > 1 مقدار b^x وقتی x به سمت منفی بی‌کران می‌رود به صفر نزدیک می‌شود. تابع نمایی و لگاریتم وارون یکدیگرند، پس b^(log_b(x)) = x برای x > 0 و log_b(b^x) = x برای هر x حقیقی.

### Worked example / مثال حل‌شده
Evaluate 2^(-3) and 3^(1/2). For 2^(-3), use b^(-x) = 1/b^x to get 1/2^3 = 1/8. For 3^(1/2), the exponent one half means the square root, so 3^(1/2) is about 1.7321. Now solve 2^x = 32 by writing both sides with the same base: 32 = 2^5, so 2^x = 2^5 and x = 5, which is legitimate because b^x with b > 1 is one-to-one. Compare with 2^x = 30, where 30 is not a power of 2; the same-base method fails and a logarithm is needed, giving x = log_2(30), about 4.9069.
مقدار 2^(-3) و 3^(1/2) را حساب کن. برای 2^(-3) از b^(-x) = 1/b^x استفاده کن تا 1/2^3 = 1/8 به دست آید. برای 3^(1/2)، توان یک‌دوم یعنی جذر، پس 3^(1/2) حدود 1.7321 است. اکنون 2^x = 32 را با نوشتن دو طرف به پایه یکسان حل کن: 32 = 2^5 پس 2^x = 2^5 و x = 5، که مجاز است چون b^x با b > 1 یک‌به‌یک است. آن را با 2^x = 30 مقایسه کن که در آن ۳۰ توانی از ۲ نیست؛ روش پایه یکسان شکست می‌خورد و لگاریتم لازم است که x = log_2(30) و حدود 4.9069 می‌دهد.

### Common mistakes / اشتباه‌های رایج
Treating an exponential as linear is the classic error: b^(x+y) is not b^x + b^y, and 2^3 is not 2 * 3. Confusing the two exponent laws is the second error: (b^x)^y = b^(x*y), which is not b^(x^y); for example (2^2)^3 = 2^6 = 64 while 2^(2^3) = 2^8 = 256. A third error is claiming b^x can equal zero or be negative, which is impossible for a real exponent with b > 0. A fourth is distributing a base across a sum inside the exponent, writing 2^(x+1) as 2^x + 2.
خطای کلاسیک خطی فرض کردن تابع نمایی است: b^(x+y) برابر b^x + b^y نیست و 2^3 برابر 2 * 3 نیست. خطای دوم اشتباه گرفتن دو قانون توان است: (b^x)^y = b^(x*y) که با b^(x^y) برابر نیست؛ مثلاً (2^2)^3 = 2^6 = 64 در حالی که 2^(2^3) = 2^8 = 256. خطای سوم ادعای امکان صفر یا منفی شدن b^x است که برای توان حقیقی و b > 0 ناممکن است. خطای چهارم پخش کردن پایه روی جمع درون توان است، یعنی نوشتن 2^(x+1) به‌صورت 2^x + 2.

## Intermediate / متوسط

### Definition / تعریف
At this level the learner manipulates exponential expressions fluently and must explain why a rewriting is valid before using it. Equations of the form b^u = b^v reduce to u = v only because the exponential is one-to-one. The function f(x) = b^x is defined for every real x and, for admissible b, is either strictly increasing or strictly decreasing. That strict monotonicity is the property that makes the function invertible, and the inverse is log_b. Recognising a growth or decay process as f(x) = A * b^x, with A the initial value and b the constant multiplier per unit, is the main modelling step at this level.
در این سطح یادگیرنده عبارات نمایی را روان دستکاری می‌کند و باید پیش از استفاده توضیح دهد چرا بازنویسی معتبر است. معادله‌های شکل b^u = b^v تنها به این دلیل به u = v کاهش می‌یابند که تابع نمایی یک‌به‌یک است. تابع f(x) = b^x برای هر x حقیقی تعریف شده و برای b مجاز یا اکیداً صعودی است یا اکیداً نزولی. همین یکنوایی اکید خاصیتی است که تابع را وارون‌پذیر می‌کند و وارون آن log_b است. شناختن یک فرایند رشد یا کاهش به‌صورت f(x) = A * b^x، با A مقدار آغازین و b ضریب ثابت در هر واحد، گام اصلی مدل‌سازی در این سطح است.

### Rule and conditions / قاعده و شرطها
Exponent laws, valid for b > 0 and real x and y: b^(x+y) = b^x * b^y, b^(x-y) = b^x / b^y, (b^x)^y = b^(x*y), b^0 = 1, and b^(-x) = 1/b^x. Note that b^(x+y) = b^x * b^y requires a common base; the expression (b*c)^x factors as b^x * c^x, but b^x + c^x does not factor. Because b^x is one-to-one, b^u = b^v is equivalent to u = v, and this equivalence is the basis of every same-base solution. If the two sides cannot share a base, take a logarithm of both sides and use log_b(b^x) = x.
قوانین توان، معتبر برای b > 0 و x و y حقیقی: b^(x+y) = b^x * b^y، b^(x-y) = b^x / b^y، (b^x)^y = b^(x*y)، b^0 = 1 و b^(-x) = 1/b^x. توجه کن که b^(x+y) = b^x * b^y به پایه مشترک نیاز دارد؛ عبارت (b*c)^x به b^x * c^x تجزیه می‌شود اما b^x + c^x تجزیه نمی‌شود. چون b^x یک‌به‌یک است، b^u = b^v با u = v هم‌ارز است و همین هم‌ارزی پایه هر حل با روش پایه یکسان است. اگر دو طرف پایه مشترک نپذیرند، از دو طرف لگاریتم بگیر و از log_b(b^x) = x استفاده کن.

### Worked example / مثال حل‌شده
Solve 3^(2x - 1) = 27. Write 27 as a power of 3: 27 = 3^3. Then 3^(2x - 1) = 3^3, and because the base is the same and greater than 1, the exponents are equal: 2x - 1 = 3, so 2x = 4 and x = 2. Check by substitution: 3^(2*2 - 1) = 3^3 = 27, which agrees. Now solve 5 * 2^x = 80. Divide both sides by 5 to isolate the exponential: 2^x = 16. Since 16 = 2^4, the answer is x = 4. The division is legitimate because 5 is a nonzero constant and does not depend on x.
معادله 3^(2x - 1) = 27 را حل کن. ۲۷ را به‌صورت توانی از ۳ بنویس: 27 = 3^3. آنگاه 3^(2x - 1) = 3^3 و چون پایه یکسان و بزرگ‌تر از ۱ است، توان‌ها برابرند: 2x - 1 = 3 پس 2x = 4 و x = 2. با جای‌گذاری بررسی کن: 3^(2*2 - 1) = 3^3 = 27 که سازگار است. اکنون 5 * 2^x = 80 را حل کن. دو طرف را بر ۵ تقسیم کن تا تابع نمایی جدا شود: 2^x = 16. چون 16 = 2^4 پاسخ x = 4 است. این تقسیم مجاز است چون ۵ ثابتی ناصفر است و به x وابسته نیست.

### Common mistakes / اشتباه‌های رایج
Adding the exponents when the bases are multiplied is a frequent error: b^x * b^y = b^(x+y), so the exponents add, but the bases must be equal, and b^x * c^y cannot be merged. A second error is applying a power to each term of a sum, writing (b + c)^x as b^x + c^x. A third is dropping a constant multiplier incorrectly, for example replacing 5 * 2^x by 10^x. A fourth is using the same-base shortcut when the bases differ; 2^x = 3^y does not imply x = y, and a logarithm is required.
جمع کردن توان‌ها هنگامی که پایه‌ها ضرب می‌شوند خطای رایجی است: b^x * b^y = b^(x+y) پس توان‌ها جمع می‌شوند، اما پایه‌ها باید برابر باشند و b^x * c^y ترکیب نمی‌شود. خطای دوم اعمال توان به هر جمله یک جمع است، یعنی نوشتن (b + c)^x به‌صورت b^x + c^x. خطای سوم حذف نادرست ضریب ثابت است، مثلاً تبدیل 5 * 2^x به 10^x. خطای چهارم استفاده از میان‌بر پایه یکسان هنگام تفاوت پایه‌ها است؛ 2^x = 3^y به x = y منجر نمی‌شود و لگاریتم لازم است.

## Advanced / پیشرفته

### Definition / تعریف
At this level the learner states the hypotheses of each law, distinguishes an identity from an equation, and recognises when a transformation changes the solution set. For b > 0 with b != 1, the map x -> b^x is a continuous group isomorphism from the additive group of the reals onto the multiplicative group of the positive reals, and log_b is its inverse. This is the precise sense in which an exponential converts addition into multiplication, and it is why the additive exponent laws hold. The number e is defined by the property that the area under y = 1/t from 1 to e is exactly 1, or equivalently as the limit of (1 + 1/n)^n as n grows without bound; e^x is the unique function equal to its own derivative, which is why it is the natural base for calculus.
در این سطح یادگیرنده فرض‌های هر قانون را بیان می‌کند، اتحاد را از معادله جدا می‌کند و تشخیص می‌دهد چه زمانی یک تبدیل مجموعه جواب را تغییر می‌دهد. برای b > 0 با b != 1، نگاشت x -> b^x یک یک‌ریختی پیوسته گروهی از گروه جمعی اعداد حقیقی بر گروه ضربی اعداد حقیقی مثبت است و log_b وارون آن است. این معنای دقیق تبدیل جمع به ضرب توسط تابع نمایی است و دلیل برقراری قوانین جمعی توان. عدد e با این خاصیت تعریف می‌شود که مساحت زیر y = 1/t از ۱ تا e دقیقاً ۱ باشد، یا به‌طور هم‌ارز به‌عنوان حد (1 + 1/n)^n هنگامی که n بی‌کران رشد می‌کند؛ e^x یگانه تابعی است که با مشتق خود برابر است و همین آن را پایه طبیعی حساب دیفرانسیل می‌کند.

### Rule and conditions / قاعده و شرطها
For positive real b, the real-exponent identities b^(u+v) = b^u*b^v and (b^u)^v = b^(u*v) also hold when b = 1. Distinguish these identities from injectivity: the same-base inference b^u = b^v implies u = v requires b != 1, since b = 1 gives a constant function. The base of log_b must likewise be positive and different from 1. Over the reals b^x is positive for positive b, so b^x = -5 has no real solution. Taking natural logarithms of positive expressions preserves equality because ln is injective; do not apply ln to a nonpositive side.
برای b حقیقی مثبت، اتحادهای توان b^(u+v) = b^u*b^v و (b^u)^v = b^(u*v) حتی برای b = 1 برقرارند. این اتحادها را از یک‌به‌یک بودن جدا کن: استنتاج u = v از b^u = b^v با پایه یکسان به b != 1 نیاز دارد چون b = 1 تابعی ثابت می‌دهد. پایه log_b نیز باید مثبت و متفاوت از 1 باشد. روی اعداد حقیقی b^x برای b مثبت همواره مثبت است، پس b^x = -5 جواب حقیقی ندارد. گرفتن لگاریتم طبیعی از عبارت‌های مثبت برابری را حفظ می‌کند چون ln یک‌به‌یک است؛ برای طرف نامثبت از ln استفاده نکن.

### Worked example / مثال حل‌شده
Solve 2^x = 30 over the reals and give the answer exactly and numerically. The bases cannot be matched, so take a natural logarithm of both sides: ln(2^x) = ln(30). By the power rule, x*ln(2) = ln(30), so x = ln(30)/ln(2). That quotient is the exact answer; numerically it is about 3.4012 / 0.6931, which is about 4.9069. Verify by substitution: 2^4.9069 is about 30, which agrees. Note what the logarithm step relied on: ln is injective on the positive reals and both sides were positive, so no solution was lost and none was introduced. If the equation had been 2^x = -30, the same step would have been invalid because the right side is not in the domain of the logarithm, and indeed there is no real solution.
معادله 2^x = 30 را روی اعداد حقیقی حل کن و پاسخ را دقیق و عددی بده. پایه‌ها را نمی‌توان یکسان کرد، پس از دو طرف لگاریتم طبیعی بگیر: ln(2^x) = ln(30). بر پایه قاعده توان x*ln(2) = ln(30) پس x = ln(30)/ln(2). این خارج قسمت پاسخ دقیق است؛ عددی حدود 3.4012 / 0.6931 یعنی تقریباً 4.9069 می‌شود. با جای‌گذاری بررسی کن: 2^4.9069 حدود ۳۰ است که سازگار است. توجه کن گام لگاریتم بر چه چیزی تکیه داشت: ln روی اعداد حقیقی مثبت یک‌به‌یک است و دو طرف مثبت بودند، پس نه جوابی از دست رفت و نه جوابی اضافه شد. اگر معادله 2^x = -30 بود همین گام نامعتبر می‌شد چون سمت راست در دامنه لگاریتم نیست، و در واقع جواب حقیقی وجود ندارد.

### Common mistakes / اشتباه‌های رایج
A recurring error is applying a logarithm to a sum, writing ln(a + b) as ln(a) + ln(b); the logarithm turns products into sums, never sums into sums. A second is treating (b^x)^y and b^(x^y) as interchangeable, which they are not, as the advanced reading of the power law shows. A third is forgetting that the same-base method requires b != 1, so an equation such as 1^x = 1 is not evidence that x is determined. A fourth is reporting a numerical approximation as though it were exact; x = ln(30)/ln(2) is exact while 4.9069 is a rounded value with limited precision.
خطای پرتکرار اعمال لگاریتم به یک جمع است، یعنی نوشتن ln(a + b) به‌صورت ln(a) + ln(b)؛ لگاریتم ضرب را به جمع تبدیل می‌کند و هرگز جمع را به جمع. خطای دوم یکسان دانستن (b^x)^y و b^(x^y) است که چنین نیست، چنان‌که خوانش پیشرفته قاعده توان نشان می‌دهد. خطای سوم فراموش کردن نیاز روش پایه یکسان به b != 1 است، پس معادله‌ای مانند 1^x = 1 شاهدی بر تعیین x نیست. خطای چهارم گزارش تقریب عددی به‌جای پاسخ دقیق است؛ x = ln(30)/ln(2) دقیق است در حالی که 4.9069 مقداری گردشده با دقت محدود است.
