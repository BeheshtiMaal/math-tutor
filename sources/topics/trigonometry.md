# Trigonometry / مثلثات

Original MathTutor curated notes (Phase W3). Project exposition, not a textbook transcript. Reference: Calculus Volume 1, sections 1.3 (Trigonometric Functions) and 3.5 (Derivatives of Trigonometric Functions). Checkable formulas were verified with SymPy; see `sources/manifests/curated_verification.json`.

## Beginner / مبتدی

### Definition / تعریف
Angle measure comes first: without deciding whether the input is in degrees or radians, every value is ambiguous. Start on the unit circle, name the coordinates, and connect the triangle ratio to the circle point. On the unit circle, an angle t measured in radians counterclockwise from the positive x-axis marks a point (cos(t), sin(t)). So the cosine is the x-coordinate and the sine is the y-coordinate of that point. Equivalently, in a right triangle the sine of an acute angle is the ratio of the opposite side to the hypotenuse, and the cosine is the ratio of the adjacent side to the hypotenuse. The tangent is defined as tan(t) = sin(t)/cos(t) wherever cos(t) is nonzero. One full turn is 2*pi radians, which equals 360 degrees, so pi radians equals 180 degrees.
اندازه زاویه نخستین چیز است: تا وقتی مشخص نشود ورودی بر حسب درجه است یا رادیان، هر مقدار مبهم می‌ماند. از دایره واحد شروع کن، مختصات را نام بگذار و نسبت مثلثاتی را به نقطه روی دایره پیوند بده. روی دایره واحد، زاویه t که بر حسب رادیان و پادساعتگرد از محور مثبت x اندازه گرفته می‌شود، نقطه (cos(t), sin(t)) را نشان می‌دهد. پس کسینوس مختص x و سینوس مختص y آن نقطه است. به‌طور هم‌ارز، در مثلث قائم‌الزاویه سینوس یک زاویه حاده نسبت ضلع مقابل به وتر و کسینوس نسبت ضلع مجاور به وتر است. تانژانت به‌صورت tan(t) = sin(t)/cos(t) تعریف می‌شود، هر جا cos(t) ناصفر باشد. یک دور کامل 2*pi رادیان یعنی ۳۶۰ درجه است، پس pi رادیان برابر ۱۸۰ درجه است.

### Rule and conditions / قاعده و شرطها
Range: -1 <= sin(t) <= 1 and -1 <= cos(t) <= 1 for every real t. Period: sin(t + 2*pi) = sin(t) and cos(t + 2*pi) = cos(t), so the sine and cosine have period 2*pi, while tan has period pi. Domain: sine and cosine accept every real number; tangent is undefined exactly where cos(t) = 0, that is at t = pi/2 + k*pi for integer k. The Pythagorean identity sin(t)^2 + cos(t)^2 = 1 holds for every real t and follows directly from the unit circle. The remaining identities follow from it: 1 + tan(t)^2 = sec(t)^2 and 1 + cot(t)^2 = csc(t)^2, where sec(t) = 1/cos(t) and csc(t) = 1/sin(t). Signs by quadrant: all six functions are positive in the first quadrant, and each of the others has its own sign pattern.
برد: برای هر t حقیقی، -1 <= sin(t) <= 1 و -1 <= cos(t) <= 1. دوره: sin(t + 2*pi) = sin(t) و cos(t + 2*pi) = cos(t)، پس سینوس و کسینوس دوره 2*pi دارند و تانژانت دوره pi. دامنه: سینوس و کسینوس هر عدد حقیقی را می‌پذیرند؛ تانژانت دقیقاً آنجا تعریف نشده است که cos(t) = 0، یعنی در t = pi/2 + k*pi برای k صحیح. اتحاد فیثاغورسی sin(t)^2 + cos(t)^2 = 1 برای هر t حقیقی برقرار است و مستقیماً از دایره واحد نتیجه می‌شود. بقیه اتحادها از آن می‌آیند: 1 + tan(t)^2 = sec(t)^2 و 1 + cot(t)^2 = csc(t)^2، که در آن‌ها sec(t) = 1/cos(t) و csc(t) = 1/sin(t). علامت‌ها بر حسب ربع: هر شش تابع در ربع اول مثبت‌اند و هر یک از بقیه الگوی علامت خود را دارد.

### Worked example / مثال حل‌شده
Find sin, cos and tan of pi/6. On the unit circle, pi/6 is 30 degrees, and the point has coordinates (sqrt(3)/2, 1/2), so cos(pi/6) = sqrt(3)/2 which is about 0.8660, and sin(pi/6) = 1/2 = 0.5. Then tan(pi/6) = sin/cos = (1/2)/(sqrt(3)/2) = 1/sqrt(3) = sqrt(3)/3, about 0.5774. Check the Pythagorean identity: (1/2)^2 + (sqrt(3)/2)^2 = 1/4 + 3/4 = 1, which agrees. Now find tan(pi/2). Since cos(pi/2) = 0, the quotient sin/cos has a zero denominator, so tan(pi/2) is undefined rather than infinite; writing it as a very large number would misstate the situation.
مقدار سینوس، کسینوس و تانژانت pi/6 را بیاب. روی دایره واحد pi/6 یعنی ۳۰ درجه و نقطه مختصات (sqrt(3)/2, 1/2) دارد، پس cos(pi/6) = sqrt(3)/2 که حدود 0.8660 است و sin(pi/6) = 1/2 = 0.5. آنگاه tan(pi/6) = sin/cos = (1/2)/(sqrt(3)/2) = 1/sqrt(3) = sqrt(3)/3 و حدود 0.5774 است. اتحاد فیثاغورسی را بررسی کن: (1/2)^2 + (sqrt(3)/2)^2 = 1/4 + 3/4 = 1 که سازگار است. اکنون tan(pi/2) را بیاب. چون cos(pi/2) = 0، خارج قسمت sin/cos مخرج صفر دارد، پس tan(pi/2) تعریف‌نشده است نه بی‌نهایت؛ نوشتن آن به‌صورت عددی بسیار بزرگ وضعیت را نادرست بیان می‌کند.

### Common mistakes / اشتباه‌های رایج
Mixing degrees and radians is the most common error; in calculus every angle is in radians, and treating pi/6 as if it were 6 degrees gives a wrong value. A second error is assuming the sine is linear, writing sin(a + b) as sin(a) + sin(b); the correct expansion is sin(a)*cos(b) + cos(a)*sin(b). A third is forgetting that tangent has vertical asymptotes where the cosine vanishes, so tan is undefined rather than merely large. A fourth is using the Pythagorean identity with a sign that does not match the quadrant, for example taking sin(t) = +sqrt(1 - cos(t)^2) when t lies in the third quadrant where the sine is negative.
آمیختن درجه و رادیان رایج‌ترین خطا است؛ در حساب دیفرانسیل هر زاویه بر حسب رادیان است و در نظر گرفتن pi/6 به‌عنوان ۶ درجه مقدار نادرست می‌دهد. خطای دوم فرض خطی بودن سینوس است، یعنی نوشتن sin(a + b) به‌صورت sin(a) + sin(b)؛ بسط درست sin(a)*cos(b) + cos(a)*sin(b) است. خطای سوم فراموش کردن مجانب‌های قائم تانژانت در نقاطی است که کسینوس صفر می‌شود، پس tan تعریف‌نشده است نه فقط بزرگ. خطای چهارم به‌کارگیری اتحاد فیثاغورسی با علامتی که با ربع سازگار نیست، مثلاً گرفتن sin(t) = +sqrt(1 - cos(t)^2) هنگامی که t در ربع سوم است و سینوس منفی می‌باشد.

## Intermediate / متوسط

### Definition / تعریف
At this level the learner simplifies expressions and solves trigonometric equations, which requires the identities, the periodicity, and the reference-angle method. An identity is an equation true for every value in its domain, while a conditional equation is true only for some values. sin(t)^2 + cos(t)^2 = 1 is an identity; sin(t) = 1/2 is conditional. The sum formulas are sin(a + b) = sin(a)*cos(b) + cos(a)*sin(b) and cos(a + b) = cos(a)*cos(b) - sin(a)*sin(b), and the double-angle formulas follow by setting a = b: sin(2t) = 2*sin(t)*cos(t) and cos(2t) = cos(t)^2 - sin(t)^2. Recognising which identity applies is the skill at this level.
در این سطح یادگیرنده عبارات را ساده و معادله‌های مثلثاتی را حل می‌کند، که به اتحادها، تناوب و روش زاویه مرجع نیاز دارد. اتحاد معادله‌ای است که برای هر مقدار در دامنه‌اش درست است، در حالی که معادله شرطی تنها برای برخی مقادیر درست است. sin(t)^2 + cos(t)^2 = 1 اتحاد است و sin(t) = 1/2 شرطی. فرمول‌های جمع عبارت‌اند از sin(a + b) = sin(a)*cos(b) + cos(a)*sin(b) و cos(a + b) = cos(a)*cos(b) - sin(a)*sin(b)، و فرمول‌های زاویه دوبرابر با گذاشتن a = b به دست می‌آیند: sin(2t) = 2*sin(t)*cos(t) و cos(2t) = cos(t)^2 - sin(t)^2. تشخیص اینکه کدام اتحاد به کار می‌آید مهارت این سطح است.

### Rule and conditions / قاعده و شرطها
Because sine and cosine are periodic with period 2*pi, an equation such as sin(t) = 1/2 has infinitely many solutions, and the general solution is written with an integer parameter. For sin(t) = c with |c| <= 1, the reference solution is t_0 = arcsin(c) and the full family is t = t_0 + 2*k*pi or t = pi - t_0 + 2*k*pi for integer k. For cos(t) = c, the family is t = ± arccos(c) + 2*k*pi. For tan(t) = c the period is pi, so the family is t = arctan(c) + k*pi. An equation with |c| > 1 has no real solution. When both sides contain the same function, factoring is usually preferable to dividing, because division can discard solutions.
چون سینوس و کسینوس دوره 2*pi دارند، معادله‌ای مانند sin(t) = 1/2 بی‌شمار جواب دارد و جواب کلی با یک پارامتر صحیح نوشته می‌شود. برای sin(t) = c با |c| <= 1 جواب مرجع t_0 = arcsin(c) است و خانواده کامل t = t_0 + 2*k*pi یا t = pi - t_0 + 2*k*pi برای k صحیح. برای cos(t) = c خانواده t = ± arccos(c) + 2*k*pi است. برای tan(t) = c دوره pi است پس خانواده t = arctan(c) + k*pi. معادله با |c| > 1 جواب حقیقی ندارد. هنگامی که دو طرف تابع یکسان دارند، تجزیه معمولاً بر تقسیم ترجیح دارد چون تقسیم می‌تواند جواب‌ها را حذف کند.

### Worked example / مثال حل‌شده
Solve 2*sin(t)^2 - sin(t) - 1 = 0 for real t. Treat u = sin(t) and solve 2*u^2 - u - 1 = 0. The discriminant is 1 + 8 = 9, so u = (1 ± 3)/4, giving u = 1 or u = -1/2. For u = 1, sin(t) = 1 gives t = pi/2 + 2*k*pi. For u = -1/2, the reference solution is t_0 = arcsin(-1/2) = -pi/6, and the family is t = -pi/6 + 2*k*pi or t = pi - (-pi/6) + 2*k*pi = 7*pi/6 + 2*k*pi. Both families are required; discarding the second would lose half the solutions. Substitute one value, t = 7*pi/6, to check: sin(7*pi/6) = -1/2, so 2*(1/4) - (-1/2) - 1 = 1/2 + 1/2 - 1 = 0, which agrees.
معادله 2*sin(t)^2 - sin(t) - 1 = 0 را برای t حقیقی حل کن. u = sin(t) بگیر و 2*u^2 - u - 1 = 0 را حل کن. مبیّن 1 + 8 = 9 است، پس u = (1 ± 3)/4 یعنی u = 1 یا u = -1/2. برای u = 1، رابطه sin(t) = 1 مقدار t = pi/2 + 2*k*pi می‌دهد. برای u = -1/2 جواب مرجع t_0 = arcsin(-1/2) = -pi/6 است و خانواده t = -pi/6 + 2*k*pi یا t = pi - (-pi/6) + 2*k*pi = 7*pi/6 + 2*k*pi. هر دو خانواده لازم‌اند؛ حذف دومی نیمی از جواب‌ها را از دست می‌دهد. برای بررسی یک مقدار مانند t = 7*pi/6 را جای‌گذاری کن: sin(7*pi/6) = -1/2 پس 2*(1/4) - (-1/2) - 1 = 1/2 + 1/2 - 1 = 0 که سازگار است.

### Common mistakes / اشتباه‌های رایج
Dividing both sides of a trigonometric equation by a common factor is the error that loses the most solutions; from sin(t)*cos(t) = sin(t), dividing by sin(t) discards every t with sin(t) = 0, and the correct step is to factor. A second error is reporting only the principal value from the inverse function and ignoring the second family and the period. A third is applying the sum formula as if it were linear, writing sin(a + b) as sin(a) + sin(b). A fourth is treating arccos as the reciprocal of cos; arccos(c) returns an angle while sec(c) = 1/cos(c) returns a number, and the two are unrelated.
تقسیم دو طرف یک معادله مثلثاتی بر عامل مشترک خطایی است که بیشترین جواب را از دست می‌دهد؛ از sin(t)*cos(t) = sin(t)، تقسیم بر sin(t) هر t با sin(t) = 0 را حذف می‌کند و گام درست تجزیه است. خطای دوم گزارش تنها مقدار اصلی تابع وارون و نادیده گرفتن خانواده دوم و تناوب است. خطای سوم به‌کارگیری فرمول جمع به‌صورت خطی است، یعنی نوشتن sin(a + b) به‌صورت sin(a) + sin(b). خطای چهارم یکسان دانستن arccos با وارون کسینوس است؛ arccos(c) یک زاویه برمی‌گرداند در حالی که sec(c) = 1/cos(c) یک عدد می‌دهد و این دو بی‌ارتباط‌اند.

## Advanced / پیشرفته

### Definition / تعریف
At this level the learner must justify identities, respect restricted domains, and distinguish an exact value from a numerical approximation. The trigonometric functions are most cleanly defined by their power series, which converge for every real t: sin(t) = t - t^3/3! + t^5/5! - ... and cos(t) = 1 - t^2/2! + t^4/4! - ..., with t in radians. From these series the identity sin(t)^2 + cos(t)^2 = 1 can be proved analytically rather than read off a circle, and the derivative relations follow term by term: the derivative of sin is cos and the derivative of cos is -sin. Radians are not a convention in this setting but a requirement: the derivative formulas hold only in radian measure, because the series above are expansions in radians.
در این سطح یادگیرنده باید اتحادها را توجیه کند، دامنه‌های محدود را رعایت کند و مقدار دقیق را از تقریب عددی جدا کند. توابع مثلثاتی را به پاکیزه‌ترین شکل با سری توانی تعریف می‌کنند که برای هر t حقیقی همگراست: sin(t) = t - t^3/3! + t^5/5! - ... و cos(t) = 1 - t^2/2! + t^4/4! - ...، با t بر حسب رادیان. از این سری‌ها می‌توان اتحاد sin(t)^2 + cos(t)^2 = 1 را تحلیلی اثبات کرد نه فقط از دایره خواند، و روابط مشتق جمله‌به‌جمله نتیجه می‌شوند: مشتق سینوس کسینوس و مشتق کسینوس منفی سینوس است. رادیان در این چارچوب یک قرارداد نیست بلکه یک الزام است: فرمول‌های مشتق تنها در اندازه رادیانی برقرارند، چون سری‌های بالا بسط‌هایی بر حسب رادیان‌اند.

### Rule and conditions / قاعده و شرطها
Every identity holds on the intersection of the domains of its two sides, and the domain restriction must travel with the identity. The identity 1 + tan(t)^2 = sec(t)^2 is valid only where cos(t) != 0, even though its right side looks defined more widely in some rearrangements. Identities used to simplify an equation can change the domain: multiplying by cos(t) or by sin(t) can introduce values the original expression excluded, so any candidate must be checked in the original equation. Over the reals, arcsin has range [-pi/2, pi/2] and arccos has range [0, pi]; this restriction is what makes them functions rather than relations, and it is why sin(arcsin(c)) = c for |c| <= 1 while arcsin(sin(t)) = t only for t inside that range.
هر اتحاد روی اشتراک دامنه‌های دو طرفش برقرار است و محدودیت دامنه باید همراه اتحاد بماند. اتحاد 1 + tan(t)^2 = sec(t)^2 تنها جایی معتبر است که cos(t) != 0، حتی اگر سمت راست آن در برخی بازآرایی‌ها گسترده‌تر تعریف‌شده به نظر برسد. اتحادهایی که برای ساده‌سازی معادله به کار می‌روند می‌توانند دامنه را تغییر دهند: ضرب در cos(t) یا sin(t) می‌تواند مقادیری را وارد کند که عبارت اصلی کنار گذاشته بود، پس هر کاندیدا باید در معادله اصلی بررسی شود. روی اعداد حقیقی برد arcsin بازه [-pi/2, pi/2] و برد arccos بازه [0, pi] است؛ همین محدودیت آن‌ها را تابع می‌کند نه رابطه، و به همین دلیل sin(arcsin(c)) = c برای |c| <= 1 در حالی که arcsin(sin(t)) = t تنها برای t درون آن بازه است.

### Worked example / مثال حل‌شده
Prove that (1 - cos(2t))/2 = sin(t)^2 for every real t. Start from the double-angle formula cos(2t) = cos(t)^2 - sin(t)^2 and rewrite cos(t)^2 as 1 - sin(t)^2, which uses the Pythagorean identity. Then cos(2t) = 1 - sin(t)^2 - sin(t)^2 = 1 - 2*sin(t)^2. Rearranging gives 2*sin(t)^2 = 1 - cos(2t), and dividing by 2 gives sin(t)^2 = (1 - cos(2t))/2, which is the claim. Every step is an identity valid for all real t, so the proof is complete and no domain restriction is introduced. As a numerical check, take t = pi/4: the left side is (1 - cos(pi/2))/2 = (1 - 0)/2 = 1/2, and the right side is sin(pi/4)^2 = (sqrt(2)/2)^2 = 1/2, which agrees.
ثابت کن که (1 - cos(2t))/2 = sin(t)^2 برای هر t حقیقی. از فرمول زاویه دوبرابر cos(2t) = cos(t)^2 - sin(t)^2 شروع کن و cos(t)^2 را به 1 - sin(t)^2 بازنویس، که از اتحاد فیثاغورسی استفاده می‌کند. آنگاه cos(2t) = 1 - sin(t)^2 - sin(t)^2 = 1 - 2*sin(t)^2. بازآرایی 2*sin(t)^2 = 1 - cos(2t) می‌دهد و تقسیم بر ۲ نتیجه sin(t)^2 = (1 - cos(2t))/2 را می‌دهد که همان ادعاست. هر گام اتحادی است که برای همه t حقیقی معتبر است، پس اثبات کامل است و محدودیت دامنه‌ای وارد نمی‌شود. برای بررسی عددی t = pi/4 را بگیر: سمت چپ (1 - cos(pi/2))/2 = (1 - 0)/2 = 1/2 و سمت راست sin(pi/4)^2 = (sqrt(2)/2)^2 = 1/2 است که سازگار است.

### Common mistakes / اشتباه‌های رایج
Proving an identity by manipulating both sides at once and arriving at a true statement proves nothing unless every step is reversible; the safe method is to transform one side into the other with justified steps. A second error is ignoring the domain when an identity is applied inside an equation, so that a value excluded by the original expression is reported as a solution. A third is confusing the inverse function with the reciprocal, for example reading arcsin(c) as 1/sin(c). A fourth is treating a numerical verification such as t = pi/4 as a proof; it is a check that can expose an error but cannot establish a universal claim.
اثبات یک اتحاد با دستکاری همزمان دو طرف و رسیدن به گزاره‌ای درست هیچ چیز را ثابت نمی‌کند مگر آنکه هر گام بازگشت‌پذیر باشد؛ روش ایمن تبدیل یک سمت به سمت دیگر با گام‌های موجه است. خطای دوم نادیده گرفتن دامنه هنگام به‌کارگیری اتحاد در یک معادله است، به‌طوری که مقداری که عبارت اصلی کنار گذاشته بود به‌عنوان جواب گزارش شود. خطای سوم اشتباه گرفتن تابع وارون با وارون ضربی است، مثلاً خواندن arcsin(c) به‌عنوان 1/sin(c). خطای چهارم اثبات پنداشتن یک بررسی عددی مانند t = pi/4 است؛ آن بررسی می‌تواند خطا را آشکار کند اما نمی‌تواند ادعایی کلی را ثابت کند.
