# Logarithms / لگاریتم

Original MathTutor curated notes (Phase W3). Project exposition, not a textbook transcript. Reference: College Algebra 2e, sections 6.3–6.6. Every formula stated here as checkable was verified with SymPy; the verification record is in `sources/manifests/curated_verification.json`.

## Beginner / مبتدی

### Definition / تعریف
A logarithm answers the question "what exponent do I need?". Start from one concrete power, name the base and the result, and only then write the general rule. Each symbol is defined before it is used. For a base b with b > 0 and b != 1, and a positive number x, the logarithm log_b(x) is the exponent y that makes b^y = x. So log_b(x) = y exactly when b^y = x. The base is written as a subscript. The number x is called the argument, and it must be positive. Two values follow immediately and are worth memorising: log_b(1) = 0, because b^0 = 1, and log_b(b) = 1, because b^1 = b.
لگاریتم به این پرسش پاسخ می‌دهد: «چه توانی لازم است؟». با یک توان مشخص شروع کن، پایه و حاصل را نام‌گذاری کن و تنها پس از آن قاعده کلی را بنویس. هر نماد پیش از استفاده تعریف می‌شود. برای پایه b با شرط b > 0 و b != 1، و عدد مثبت x، لگاریتم log_b(x) همان توان y است که b^y = x را برقرار می‌کند. پس log_b(x) = y دقیقاً وقتی درست است که b^y = x. پایه به‌صورت زیرنویس نوشته می‌شود. عدد x را آرگومان می‌نامیم و باید مثبت باشد. دو مقدار بی‌درنگ نتیجه می‌شوند و به یاد سپردنی‌اند: log_b(1) = 0 چون b^0 = 1، و log_b(b) = 1 چون b^1 = b.

### Rule and conditions / قاعده و شرطها
Domain: the argument must satisfy x > 0. A logarithm of zero or of a negative number is not defined among the real numbers. The base must satisfy b > 0 and b != 1; the base 1 is excluded because 1^y = 1 for every y, so no exponent could ever produce a value other than 1, and base 0 or a negative base breaks the definition for most exponents. Range: log_b(x) takes every real value. The logarithm is the inverse of exponentiation: b^(log_b(x)) = x for every x > 0, and log_b(b^y) = y for every real y.
دامنه: آرگومان باید x > 0 را برآورده کند. لگاریتم صفر یا عدد منفی در اعداد حقیقی تعریف نشده است. پایه باید b > 0 و b != 1 باشد؛ پایه ۱ کنار گذاشته می‌شود چون 1^y = 1 برای هر y، پس هیچ توانی نمی‌تواند مقداری جز ۱ بسازد، و پایه صفر یا منفی برای بیشتر توان‌ها تعریف را می‌شکند. برد: log_b(x) هر مقدار حقیقی را می‌گیرد. لگاریتم وارون توان‌رسانی است: b^(log_b(x)) = x برای هر x > 0، و log_b(b^y) = y برای هر y حقیقی.

### Worked example / مثال حل‌شده
Find log_2(8). Ask which exponent y satisfies 2^y = 8. Since 8 = 2^3, the exponent is 3, so log_2(8) = 3. Check the direction of the definition by raising the base again: 2^3 = 8, which agrees. Now find log_5(1/25). Write 1/25 as 5^(-2), because 5^(-2) = 1/5^2 = 1/25. So log_5(1/25) = -2. The negative answer is not an error: the argument is smaller than 1, and the logarithm of any number between 0 and 1 is negative when b > 1.
مقدار log_2(8) را بیاب. بپرس کدام توان y در 2^y = 8 صدق می‌کند. چون 8 = 2^3، توان ۳ است، پس log_2(8) = 3. درستی جهت تعریف را با توان‌رسانی دوباره بررسی کن: 2^3 = 8 که سازگار است. اکنون log_5(1/25) را بیاب. 1/25 را به‌صورت 5^(-2) بنویس، چون 5^(-2) = 1/5^2 = 1/25. پس log_5(1/25) = -2. پاسخ منفی خطا نیست: آرگومان کوچک‌تر از ۱ است و لگاریتم هر عدد بین ۰ و ۱ برای b > 1 منفی است.

### Common mistakes / اشتباه‌های رایج
The most frequent error is treating a logarithm as linear: log_b(x + y) is not log_b(x) + log_b(y). The sum rule applies to a product, not a sum. A second error is dropping the domain restriction when simplifying; log_b(x^2) is not 2*log_b(x) over all reals, because the left side accepts x < 0 while the right side does not, and the correct general statement over the reals is log_b(x^2) = 2*log_b(|x|). A third error is assuming a logarithm can be negative or zero in value, which is wrong: the logarithm itself takes any real value, and it is the argument that must be positive. A fourth error is writing log_b(x) when the base is 1 or when the base is not positive.
رایج‌ترین خطا خطی فرض کردن لگاریتم است: log_b(x + y) برابر log_b(x) + log_b(y) نیست. قاعده جمع به ضرب مربوط است، نه به جمع. خطای دوم حذف شرط دامنه هنگام ساده‌سازی است؛ log_b(x^2) روی همه اعداد حقیقی برابر 2*log_b(x) نیست، چون سمت چپ x < 0 را می‌پذیرد و سمت راست نه، و بیان درست و کلی روی اعداد حقیقی log_b(x^2) = 2*log_b(|x|) است. خطای سوم فرض این است که لگاریتم نمی‌تواند منفی یا صفر باشد؛ این نادرست است: خود لگاریتم هر مقدار حقیقی را می‌گیرد و این آرگومان است که باید مثبت باشد. خطای چهارم نوشتن log_b(x) با پایه ۱ یا پایه نامثبت است.

## Intermediate / متوسط

### Definition / تعریف
At this level the learner already computes single logarithms and now needs the algebraic rules, the change of base, and the reason each rule holds. Explain why the chosen rule fits the expression before applying it. The definition log_b(x) = y exactly when b^y = x is the single fact from which every rule below is derived. Treat it as a dictionary translating between two languages: a statement about exponents and a statement about logarithms. When an expression mixes both, translating one side into the other is usually the whole solution.
در این سطح یادگیرنده لگاریتم‌های ساده را محاسبه می‌کند و اکنون به قواعد جبری، تغییر پایه و دلیل درستی هر قاعده نیاز دارد. پیش از به‌کارگیری هر قاعده توضیح بده چرا آن قاعده با عبارت سازگار است. تعریف log_b(x) = y دقیقاً وقتی درست است که b^y = x، همان یگانه اصلی است که همه قواعد زیر از آن گرفته می‌شوند. آن را واژه‌نامه‌ای بدان که میان دو زبان ترجمه می‌کند: گزاره‌ای درباره توان‌ها و گزاره‌ای درباره لگاریتم‌ها. هنگامی که عبارتی هر دو را در هم می‌آمیزد، ترجمه یک سمت به سمت دیگر معمولاً تمام راه‌حل است.

### Rule and conditions / قاعده و شرطها
Product rule: log_b(x*y) = log_b(x) + log_b(y) for x > 0 and y > 0. Quotient rule: log_b(x/y) = log_b(x) - log_b(y) for x > 0 and y > 0. Power rule: log_b(x^p) = p*log_b(x) for x > 0 and any real p. Change of base: log_b(x) = log_c(x) / log_c(b) for any admissible c with c > 0 and c != 1, and in particular log_b(x) = ln(x) / ln(b). Each rule requires the arguments to be positive; the rules are statements about arguments, not about the logarithm's value, and the value may be negative. These three rules turn products into sums, quotients into differences, and powers into factors, which is exactly why logarithms were historically used to multiply large numbers by hand. The graph of y = log_b(x) is the reflection of y = b^x across the line y = x. It passes through (1, 0) and (b, 1), has a vertical asymptote at x = 0, and never touches the y-axis, because the argument must stay positive. For b > 1 the curve rises without bound but ever more slowly, so it crosses every horizontal line exactly once; for 0 < b < 1 it falls in the same way. Changing the base rescales the curve vertically only, because log_b(x) = ln(x) / ln(b).
قاعده ضرب: log_b(x*y) = log_b(x) + log_b(y) برای x > 0 و y > 0. قاعده تقسیم: log_b(x/y) = log_b(x) - log_b(y) برای x > 0 و y > 0. قاعده توان: log_b(x^p) = p*log_b(x) برای x > 0 و هر p حقیقی. تغییر پایه: log_b(x) = log_c(x) / log_c(b) برای هر c مجاز با c > 0 و c != 1، و به‌ویژه log_b(x) = ln(x) / ln(b). هر قاعده به مثبت بودن آرگومان‌ها نیاز دارد؛ این قواعد درباره آرگومان‌ها هستند نه درباره مقدار لگاریتم، و مقدار می‌تواند منفی باشد. این سه قاعده ضرب را به جمع، تقسیم را به تفاضل و توان را به ضریب تبدیل می‌کنند، و همین دلیل تاریخی استفاده از لگاریتم برای ضرب دستی اعداد بزرگ است. نمودار y = log_b(x) بازتاب y = b^x نسبت به خط y = x است. از نقطه (1, 0) و (b, 1) می‌گذرد، در x = 0 مجانب قائم دارد و هرگز به محور y نمی‌رسد، چون آرگومان باید مثبت بماند. برای b > 1 منحنی بی‌کران بالا می‌رود اما هرچه کندتر، پس هر خط افقی را دقیقاً یک بار قطع می‌کند؛ برای 0 < b < 1 به همان شکل پایین می‌آید. تغییر پایه منحنی را تنها به‌صورت قائم مقیاس می‌کند، چون log_b(x) = ln(x) / ln(b).

### Worked example / مثال حل‌شده
Expand log_3(81*x^2/y) into a sum and difference of logarithms, assuming x > 0 and y > 0. Apply the quotient rule first: log_3(81*x^2) - log_3(y). Then the product rule: log_3(81) + log_3(x^2) - log_3(y). Then the power rule: log_3(81) + 2*log_3(x) - log_3(y). Finally evaluate the constant, because 81 = 3^4, so log_3(81) = 4, giving 4 + 2*log_3(x) - log_3(y). Reverse the direction as a check by combining the parts back into one logarithm. Now use the change of base to evaluate log_7(50) numerically. Write log_7(50) = ln(50)/ln(7), and since ln(50) is about 3.9120 and ln(7) is about 1.9459, the quotient is about 2.0104. Check by raising: 7^2.0104 is about 50, which agrees.
log_3(81*x^2/y) را با فرض x > 0 و y > 0 به جمع و تفاضل لگاریتم‌ها بگشا. نخست قاعده تقسیم: log_3(81*x^2) - log_3(y). سپس قاعده ضرب: log_3(81) + log_3(x^2) - log_3(y). سپس قاعده توان: log_3(81) + 2*log_3(x) - log_3(y). در پایان مقدار ثابت را حساب کن، چون 81 = 3^4 پس log_3(81) = 4 و نتیجه 4 + 2*log_3(x) - log_3(y) است. برای بررسی جهت را برگردان و اجزا را دوباره در یک لگاریتم ترکیب کن. اکنون با تغییر پایه مقدار log_7(50) را عددی حساب کن. بنویس log_7(50) = ln(50)/ln(7) و چون ln(50) حدود 3.9120 و ln(7) حدود 1.9459 است، خارج قسمت حدود 2.0104 می‌شود. با توان‌رسانی بررسی کن: 7^2.0104 حدود ۵۰ است که سازگار است.

### Common mistakes / اشتباه‌های رایج
Applying the power rule when the exponent is outside a logarithm is a frequent error: log_b(x)^2 means (log_b(x))^2, which is a different quantity from log_b(x^2). Using the change of base with the fraction inverted is another common slip; the argument's logarithm goes in the numerator and the base's logarithm in the denominator. Expanding log_b(x + y) or log_b(x - y) with the sum or quotient rule is invalid, because those rules require a product or a quotient inside the argument. Finally, simplifying log_b(x^2) to 2*log_b(x) without checking the sign of x silently changes the domain.
به‌کارگیری قاعده توان هنگامی که توان بیرون لگاریتم است خطای رایجی است: log_b(x)^2 یعنی (log_b(x))^2 که با log_b(x^2) متفاوت است. وارون نوشتن کسر در تغییر پایه لغزش رایج دیگری است؛ لگاریتم آرگومان در صورت و لگاریتم پایه در مخرج قرار می‌گیرد. گشودن log_b(x + y) یا log_b(x - y) با قاعده جمع یا تقسیم نادرست است، چون آن قواعد به ضرب یا تقسیم درون آرگومان نیاز دارند. سرانجام، ساده‌سازی log_b(x^2) به 2*log_b(x) بدون بررسی علامت x دامنه را بی‌صدا تغییر می‌دهد.

## Advanced / پیشرفته

### Definition / تعریف
At this level the learner must state hypotheses, distinguish a computation from a proof, and handle the domain carefully. Preserve uncertainty and say exactly which claims were machine-checked. Formally, for b > 0 with b != 1, the exponential function x -> b^x is a continuous strictly monotone map from the reals onto the positive reals, and the logarithm log_b is its inverse function, defined on (0, infinity) and taking all real values. Strict monotonicity is what guarantees the inverse exists and is unique. When b > 1 the function is strictly increasing; when 0 < b < 1 it is strictly decreasing. The natural logarithm ln is the case b = e, where e is the unique real number for which the area under y = 1/t from 1 to e equals 1, approximately 2.718281828.
در این سطح یادگیرنده باید فرض‌ها را بیان کند، محاسبه را از اثبات جدا کند و دامنه را با دقت بررسی کند. عدم قطعیت را حفظ کن و دقیقاً بگو کدام ادعاها با ماشین بررسی شده‌اند. به‌صورت صوری، برای b > 0 با b != 1، تابع نمایی x -> b^x نگاشتی پیوسته و اکیداً یکنوا از اعداد حقیقی بر اعداد حقیقی مثبت است و لگاریتم log_b تابع وارون آن است که روی (0, infinity) تعریف شده و همه مقادیر حقیقی را می‌گیرد. یکنوایی اکید همان چیزی است که وجود و یگانگی وارون را تضمین می‌کند. برای b > 1 تابع اکیداً صعودی و برای 0 < b < 1 اکیداً نزولی است. لگاریتم طبیعی ln حالت b = e است، که در آن e یگانه عدد حقیقی‌ای است که مساحت زیر y = 1/t از ۱ تا e برابر ۱ می‌شود، تقریباً 2.718281828.

### Rule and conditions / قاعده و شرطها
Every rule above is an identity on the intersection of the domains of its sides, and the domain is part of the statement, not a technicality. The product and quotient rules require both arguments positive; the power rule requires a positive argument and no condition on the real exponent. Change of base requires the new base c to be admissible, and it fails at c = 1 because log_c(b) would be zero and the quotient undefined. Over the reals, log_b(x^2) = 2*log_b(|x|) for x != 0, while the familiar log_b(x^2) = 2*log_b(x) is valid only for x > 0. Over the complex numbers the logarithm becomes multi-valued, and the naive rules can fail; this tutor works over the reals and states the domain explicitly for that reason.
هر قاعده بالا اتحادی است روی اشتراک دامنه‌های دو طرف، و دامنه بخشی از خود گزاره است نه یک امر فنی. قاعده ضرب و تقسیم مثبت بودن هر دو آرگومان را لازم دارند؛ قاعده توان آرگومان مثبت می‌خواهد و بر توان حقیقی شرطی نمی‌گذارد. تغییر پایه نیاز دارد پایه جدید c مجاز باشد و در c = 1 شکست می‌خورد چون log_c(b) صفر می‌شود و خارج قسمت تعریف‌نشده است. روی اعداد حقیقی log_b(x^2) = 2*log_b(|x|) برای x != 0، در حالی که رابطه آشنای log_b(x^2) = 2*log_b(x) تنها برای x > 0 معتبر است. روی اعداد مختلط لگاریتم چندمقداری می‌شود و قواعد ساده می‌توانند شکست بخورند؛ این آموزگار روی اعداد حقیقی کار می‌کند و به همین دلیل دامنه را صریح بیان می‌کند.

### Worked example / مثال حل‌شده
Solve log_2(x) + log_2(x - 2) = 3 over the reals. The domain requires x > 0 and x - 2 > 0, so x > 2; record this before transforming, because it decides which candidate survives. Combine the left side with the product rule: log_2(x*(x - 2)) = 3. By the definition, x*(x - 2) = 2^3 = 8, so x^2 - 2x - 8 = 0. The discriminant is 4 + 32 = 36, so the roots are (2 + 6)/2 = 4 and (2 - 6)/2 = -2. The root x = -2 fails the recorded domain x > 2 and must be discarded; substituting it would have produced a logarithm of a negative number. Only x = 4 remains, and substituting it gives log_2(4) + log_2(2) = 2 + 1 = 3, which confirms the solution. This example shows why the domain check is not optional: the algebraic step produced a spurious root.
معادله log_2(x) + log_2(x - 2) = 3 را روی اعداد حقیقی حل کن. دامنه x > 0 و x - 2 > 0 را می‌خواهد، پس x > 2؛ این را پیش از تبدیل ثبت کن، چون تعیین می‌کند کدام کاندیدا می‌ماند. سمت چپ را با قاعده ضرب ترکیب کن: log_2(x*(x - 2)) = 3. بر پایه تعریف، x*(x - 2) = 2^3 = 8، پس x^2 - 2x - 8 = 0. مبیّن 4 + 32 = 36 است، پس ریشه‌ها (2 + 6)/2 = 4 و (2 - 6)/2 = -2 هستند. ریشه x = -2 شرط ثبت‌شده x > 2 را نقض می‌کند و باید کنار گذاشته شود؛ جای‌گذاری آن لگاریتم یک عدد منفی می‌داد. تنها x = 4 می‌ماند و جای‌گذاری آن log_2(4) + log_2(2) = 2 + 1 = 3 می‌دهد که پاسخ را تأیید می‌کند. این مثال نشان می‌دهد چرا بررسی دامنه اختیاری نیست: گام جبری یک ریشه ناخواسته تولید کرد.

### Common mistakes / اشتباه‌های رایج
The deepest error is solving a logarithmic equation algebraically and then reporting every root without returning to the domain; as the worked example shows, squaring, clearing denominators, or combining logarithms can each admit a value that the original equation never allowed. A second error is claiming log_b(x^2) = 2*log_b(x) for all real x, which silently extends the domain and is false for x < 0. A third is assuming the change of base is symmetric in its two arguments, when in fact log_b(x) = 1 / log_x(b) only for admissible b and x with x != 1, a relation that is easy to misapply. A fourth is treating the base 10 or the base e as special cases of the rules when they are merely convenient choices; the rules hold for every admissible base.
ژرف‌ترین خطا حل جبری معادله لگاریتمی و سپس گزارش همه ریشه‌ها بدون بازگشت به دامنه است؛ چنان‌که مثال حل‌شده نشان داد، توان‌رسانی، حذف مخرج یا ترکیب لگاریتم‌ها هر یک می‌توانند مقداری را بپذیرند که معادله اصلی هرگز اجازه نمی‌داد. خطای دوم ادعای log_b(x^2) = 2*log_b(x) برای همه x حقیقی است که دامنه را بی‌صدا گسترش می‌دهد و برای x < 0 نادرست است. خطای سوم فرض تقارن تغییر پایه در دو آرگومان آن است، در حالی که log_b(x) = 1 / log_x(b) تنها برای b و x مجاز با x != 1 برقرار است و به‌کارگیری نادرست آن آسان است. خطای چهارم ویژه دانستن پایه ۱۰ یا پایه e در قواعد است، در حالی که این‌ها فقط انتخاب‌هایی راحت‌اند و قواعد برای هر پایه مجاز برقرارند.
